# Neovim キーバインディング

## リーダーキー
`Space` (以下のキーと組み合わせて使用)

## ファイル操作 (Neo-tree)
| キー | 動作 | 説明 |
| :--- | :--- | :--- |
| `Leader` + `e` | エクスプローラー | Neo-tree (ファイルツリー) の開閉 |

## ウィンドウ操作
| キー | 動作 | 説明 |
| :--- | :--- | :--- |
| `Ctrl` + `h` | 左を選択 | 左のウィンドウにフォーカス移動 |
| `Ctrl` + `j` | 下を選択 | 下のウィンドウにフォーカス移動 |
| `Ctrl` + `k` | 上を選択 | 上のウィンドウにフォーカス移動 |
| `Ctrl` + `l` | 右を選択 | 右のウィンドウにフォーカス移動 |

## 編集操作
| キー | モード | 動作 | 説明 |
| :--- | :--- | :--- | :--- |
| `<` | Visual | 左へインデント | インデント後も選択状態を維持 |
| `>` | Visual | 右へインデント | インデント後も選択状態を維持 |
| `Esc` | Normal | ハイライト解除 | 検索ハイライトを消去 (`:nohl`) |

## LSP (開発支援)
| キー | 動作 | 説明 |
| :--- | :--- | :--- |
| `K` | ホバー表示 | カーソル下の型の定義やドキュメントを表示 |
| `gd` | 定義へジャンプ | 変数や関数の定義元へ移動 |
| `Leader` + `ca` | コードアクション | 修正提案やリファクタリングメニューを表示 |
| `Leader` + `d` | 診断表示 | カーソル行のエラー詳細をポップアップ表示 |
| `[d` | 前の診断 | 前のエラー/警告箇所へ移動 |
| `]d` | 次の診断 | 次のエラー/警告箇所へ移動 |
| `Leader` + `q` | 診断一覧 | ファイル内の全診断をリスト表示 |

## デバッグ (DAP)
| キー | 動作 | 説明 |
| :--- | :--- | :--- |
| `Leader` + `b` | ブレークポイント | ブレークポイントの設置/解除 |
| `Leader` + `B` | 条件付きBP | 条件付きブレークポイント等の設定 |
| `F5` | 実行 / 続行 | デバッグ開始または次のブレークポイントまで実行 |
| `F10` | ステップオーバー | 関数の中に入らずに次へ進む |
| `F11` | ステップイン | 関数の中に入る |
| `F12` | ステップアウト | 関数から抜ける |
