# 🚀 Neovim 最強ツールガイド (KEYBINDINGS)

このファイルは，現在の設定に基づいた主要なキーバインドをまとめたものです．
**render-markdown.nvim** が有効な場合，Neovim内で美しく表示されます．

---

## 💎 1. Snacks.nvim (新機能 & 便利ツール)
モダンなUIと高速なツール群を提供します．

### 📦 Git 操作 (Lazygit)
| キー | 動作 | 説明 |
| :--- | :--- | :--- |
| `Leader` + `l` + `g` | **Lazygit 起動** | フローティング窓でGit操作画面を開く |
| `Leader` + `l` + `f` | **ファイル履歴** | 今開いているファイルの変更履歴を表示 |
| `Leader` + `l` + `l` | **リポジトリログ** | プロジェクト全体のGitログを表示 |

### ✨ UI・UX 機能 (自動有効)
- **滑らかスクロール**: `Ctrl+d/u` 等の移動がスムーズになります．
- **インデントガイド**: コードの階層に縦線が表示されます．
- **単語ハイライト**: カーソル下の単語と同じものを自動強調．
- **モダンUI**: ファイル名変更(`input`)や選択(`select`)がリッチになります．

## 🔍 2. 検索・ファイル操作

### 🔭 Telescope (あいまい検索)
| キー | 動作 | 説明 |
| :--- | :--- | :--- |
| `Leader` + `f` + `f` | **ファイル検索** | ファイル名で探す |
| `Leader` + `f` + `g` | **全文検索** | 文字列を検索する (grep) |
| `Leader` + `f` + `b` | **バッファ検索** | 開いているファイルから探す |
| `Leader` + `f` + `h` | **ヘルプ検索** | Neovimヘルプを検索する |

### 🌳 Neo-tree (サイドバー)
| キー | 動作 | 説明 |
| :--- | :--- | :--- |
| `Leader` + `e` | **エクスプローラー** | 左側のファイルツリーの開閉 |

### 🪟 ウィンドウ操作
| キー | 動作 | 説明 |
| :--- | :--- | :--- |
| `Ctrl` + `h/j/k/l` | **フォーカス移動** | 左/下/上/右のウィンドウへ移動 |
| `Esc` (Normal) | **ハイライト解除** | 検索後の黄色い色付けを消す (`:nohl`) |

## 🛠️ 3. 開発支援 (LSP / 編集)

### 💡 コーディング (LSP)
| キー | 動作 | 説明 |
| :--- | :--- | :--- |
| `K` | **ホバー表示** | 型やドキュメントをポップアップ |
| `g` + `d` | **定義元へ移動** | 変数や関数の定義へジャンプ |
| `Leader` + `c` + `a` | **アクション** | 修正提案・リファクタリング実行 |
| `Leader` + `d` | **診断(行)** | 今の行のエラー詳細を表示 |
| `[` + `d` / `]` + `d` | **診断移動** | 前/次のエラー箇所へジャンプ |
| `Leader` + `q` | **診断一覧** | ファイル内の全エラーをリスト表示 |

### 📝 編集・コメント
| キー | 動作 | 説明 |
| :--- | :--- | :--- |
| `g` + `c` + `c` | **行コメント** | 今の行をコメントアウト/解除 |
| `g` + `c` (Visual) | **範囲コメント** | 選択範囲をコメントアウト/解除 |
| `<` / `>` (Visual) | **インデント** | 選択範囲を左右にずらす (選択維持) |

## 🐞 4. デバッグ (DAP)
| キー | 動作 | 説明 |
| :--- | :--- | :--- |
| `F5` | **開始 / 続行** | デバッグを開始/次まで進む |
| `Leader` + `b` | **BP切り替え** | 停止点(ブレークポイント)を設置/解除 |
| `F10` | **ステップオーバー** | 次の行へ進む (中に入らない) |
| `F11` | **ステップイン** | 関数の中に入る |
| `F12` | **ステップアウト** | 関数の外へ抜ける |

---

## 💡 ヒント
- **Leaderキー** は `Space` です．
- **which-key**: キー操作に迷ったら `Space` を少し待って押すと，次のキーの候補がガイドとして表示されます．
- **Git管理**: エディタ内なら `<Leader>lg`，ターミナルなら `lg` を使い分けると快適です．
